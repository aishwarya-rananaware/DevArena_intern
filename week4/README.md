# 📊 E-Commerce Sales Analysis

An end-to-end **E-Commerce Sales Analysis** project built using **Python, Pandas, NumPy, Matplotlib, and Jupyter Notebook**.

This project was completed as part of my **Week 4 internship learning journey**, focusing on data analysis, data validation, visualization, testing, and business insights.

---

## 📌 Project Overview

The objective of this project is to analyze e-commerce sales data and extract meaningful business insights from raw transactional data.

The project follows a complete data-analysis workflow:

**Load → Explore → Validate → Clean → Analyze → Visualize → Test → Interpret**

The analysis focuses on:

- Product performance
- Regional sales performance
- Monthly sales trends
- Revenue and quantity metrics
- Data quality and validation
- Business insights

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Load and understand a real-world-style sales dataset.
2. Explore the structure and characteristics of the data.
3. Validate the dataset for common data-quality issues.
4. Clean and prepare the data for analysis.
5. Perform Exploratory Data Analysis (EDA).
6. Calculate important business metrics.
7. Create meaningful data visualizations.
8. Test the project against common edge cases.
9. Generate actionable business insights.
10. Verify that the complete analysis pipeline works correctly.

---

## 🗂️ Dataset

The project uses an e-commerce sales dataset containing **100 records and 7 columns**.

### Dataset Columns

| Column | Description |
|---|---|
| `Date` | Date of the transaction |
| `Product` | Product purchased |
| `Quantity` | Quantity sold |
| `Price` | Price per unit |
| `Customer_ID` | Unique customer identifier |
| `Region` | Customer/sales region |
| `Total_Sales` | Total sales/revenue for the transaction |

## 🔄 Project Workflow

### 1. Data Loading

The dataset is loaded from a CSV file using Pandas.

The project also includes error handling for cases such as:

- Missing dataset file
- Unexpected file-loading errors

---

### 2. Data Exploration

The dataset is explored using:

- First few records
- Column names
- Data types
- Dataset information
- Statistical summary

This helps understand the structure and characteristics of the dataset before analysis.

---

### 3. Data Validation

Several validation checks are performed to ensure data quality.

The project checks for:

- Missing required columns
- Missing values
- Duplicate records
- Invalid dates
- Invalid numeric values
- Negative quantities
- Negative prices
- Negative sales
- Zero quantities
- Blank product names
- Blank regions

A validation summary is generated to make the results easy to review.

---

### 4. Data Cleaning

The dataset is cleaned before performing analysis.

Cleaning includes:

- Removing unnecessary spaces from text fields
- Converting numeric columns to appropriate numeric types
- Converting the `Date` column to datetime format
- Checking missing values
- Checking duplicate records
- Verifying the cleaned dataset

---

### 5. Exploratory Data Analysis

Key business metrics are calculated, including:

- Total Revenue
- Total Quantity Sold
- Average Sales
- Average Price
- Number of Products
- Number of Customers
- Number of Regions
- Minimum Sale
- Maximum Sale

---

## 📈 Analysis Performed

### Product Analysis

Products are analyzed based on:

- Total revenue
- Total quantity sold
- Average price

The analysis identifies the **best-performing product based on total revenue**.

### Regional Analysis

Regional performance is analyzed using:

- Total revenue
- Total quantity sold
- Number of transactions

The analysis identifies the **best-performing region based on total revenue**.

### Monthly Sales Analysis

Transaction dates are converted into monthly periods to identify:

- Monthly revenue
- Highest-performing month
- Overall sales trends


