# PERSONAL INTRODUCTION PROGRAM

## Project Overview

It is beginner-level Python program that asks the user
for their name, age, and favorite hobby.

The program then displays a friendly Hello message using
the information provided by the user.

## What I Learned

Through this project, I learned:

- How to write a basic Python program
- How to use variables
- How to take user input using input()
- How to display output using print()
- How to work with strings
- How to run and test a Python program
- How to solve the errors 

## Setup Instructions

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python personal_intro.py

## Project Structure

- personal_intro.py - Main Python program
- README.md - Project documentation
- requirements.txt - Project dependencies
- screenshot.png - Screenshot showing the program output

## Testing

I tested the program by entering different names, ages,
and hobbies and verified that the correct welcome message
was displayed.
