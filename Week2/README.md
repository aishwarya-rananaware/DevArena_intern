# Student Grade Calculator

##  Project Overview

The Student Grade Calculator is a simple Python program that takes a student's name and marks as input and calculates the student's grade.

The program also displays an encouraging message based on the grade.

This project was created as part of Week 2 Python practice to learn decision-making, loops, functions, input validation, and basic error handling.



##  Project Objectives

The main objectives of this project are:

- To understand `if-elif-else` statements
- To use comparison operators
- To understand and use `while` loops
- To create and use functions
- To validate user input
- To handle invalid inputs using `try-except`
- To practice testing a Python program


##  Features

- Takes the student's name as input
- Takes marks between 0 and 100
- Calculates the student's grade
- Displays an encouraging message
- Rejects marks below 0
- Rejects marks above 100
- Handles non-numeric input
- Repeats the input process until valid marks are entered


## program Logic

| 90–100 | Grade A | Excellent! Keep up the great work! 
| 80–89 | Grade B | Very Good! Keep it up! 
| 70–79 | Grade C | Good job! Keep improving! 
| 60–69 | Grade D | You passed! Keep working hard! 
| 0–59 | Grade F | Don't give up! You can improve!
